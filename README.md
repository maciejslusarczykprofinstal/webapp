# WebApp

To jest moja pierwsza aplikacja webowa 🚀

## Zawartość repozytorium
- `index.html` – główny plik HTML
- `templates/` – szablony
- `assets/` – pliki statyczne (grafiki, CSS, JS)
- `.gitignore` – plik ignorujący niepotrzebne rzeczy
